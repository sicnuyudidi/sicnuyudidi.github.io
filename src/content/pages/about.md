## 关于本站

这里记录 **LLM 推理引擎**相关的源码拆解和工程实践——显存预算、KV cache、调度、性能调优这些偏底层的话题。

写作偏好是**把术语讲清楚**：每个新概念尽量给出「一句话定义 + 生活类比 + 反例边界」，技术结论尽量带上可核对的证据（文件路径 + 行号 + commit SHA），而不是只给结论。

## 这个博客怎么搭的

| 组件 | 选择 |
| --- | --- |
| 静态生成器 | [Astro](https://astro.build/) |
| 主题 | [Astro Paper](https://github.com/satnaing/astro-paper) |
| 评论 | [Giscus](https://giscus.app/)（基于 GitHub Discussions） |
| 托管 | [GitHub Pages](https://pages.github.com/) |
| 部署 | GitHub Actions（推送即上线） |

## 本站特性

- 支持浅色/深色模式，跟随系统
- 静态搜索（PageFind），无需后端
- 文章支持 LaTeX 数学公式
- 评论基于 GitHub Discussions，数据存在本仓库里
- 响应式布局，手机可读

## 关于评论

评论区用的是 Giscus，**需要 GitHub 账号才能发言**。评论会同步出现在本仓库的 Discussions 里——你可以在那边直接参与讨论，也可以在这里留言，两边是同一份数据。
